## 候选拒绝与改选

实际解码审阅71张候选；未采用其余53张。同一菜的多个合格视角只取一张，优先成品清楚、主体居中、卡片和详情裁切可辨识的图。重点排除：

- 太阳蛋：候选混有主菜、土豆或吐司，并有煎脆边缘；本菜谱为微波制蛋，不直接套用这些早餐拼盘。
- 完美水煮蛋：候选呈干燥全熟蛋黄，不用于特殊交替温度做法的封面。
- 蛋三明治：舍弃明显多出生菜或鸡蛋切片的图，采用蛋沙拉吐司。
- 皮蛋豆腐及凉拌豆腐：舍弃大量柴鱼片、姜泥或整块冷奴的候选；选择无这些额外主料的皮蛋豆腐。
- 蒸水蛋：排除土豆、豌豆或三色蛋版本，采用文件说明明确为普通蒸蛋的照片。
- 煎烤羊排：排除生羊排，改选熟制孜然羊排。
- 金枪鱼三明治：法式面包、黑麦厚片和未压烤版本与当前方形吐司轻食机做法不符。
- B52：一张明确使用STROH 80而非当前伏特加；另一张人物占主体，成品裁切不佳。
- 炒年糕：Char Koay Kak及韩式辣炒年糕的形状、酱汁或主要配料不同。
- 炒青菜与清炒花菜：候选多出豆腐、蘑菇、米饭、胡萝卜或同时展示两盘；不为了补数采用。
- 牛奶燕麦：米乳粥原料不同，另一个燕麦候选加了不对应的浓稠浇头；保持缺图。
- 咖喱炒蟹、意式烤鸡：南印度干式蟹咖喱与重调味整鸡腿不贴合本菜谱。
- 脆皮豆腐：仅油炸、未裹蛋和收酱汁的照片不是此菜谱最终成品。
- 馄饨：排除炸馄饨，以及带其他餐点的杂乱视角。
- 酸梅汤：未采用未开封浓缩瓶作为已调制成品图。
- 响油鳝丝：候选有大量绿叶配料，未用于姜蒜鳝丝版本。
- 生汆丸子汤：炸丸子和非丸子肉片版本与汆丸子做法不符。
- 胡萝卜甜糕：不采用制作中的大锅图；取已盛装的奶甜糕与腰果。
- 螺蛳粉：排除未开封料包、加虾或卤蛋版本及模糊旧图；采用原味成品图。

剩余缺图不是适合真实照片已全部耗尽；本批只采用审过且吻合的素材，因此未启动AI生成。
