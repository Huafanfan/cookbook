# CB-013：网上真实照片补图记录

日期：2026-09-30。范围见 [CB-013](../../features/CB-013-open-license-cover-batch.md)，来源与署名方式见 [ADR-0008](../../decisions/ADR-0008-open-photo-attribution.md)。

## 结果与边界

新增 20 张真实照片，本地有封面菜谱从 183/371 增至 203/371，剩余 168 道缺图；本轮没有调用 imagegen 或自建图像 API。没有改菜谱 JSON，没有覆盖实施前已有的图片，没有部署或推送。照片代表相应菜品外观，不能作为当前配方的试做证明；装盘、少量装饰与背景配餐允许不同，不把其他主要食材或其他菜种套进来。

采用文件的作者、标题、原文件页与许可的唯一权威位置为 [图片来源与许可页](../../../public/image-credits.html)。公开领域、CC BY 与 CC BY-SA 的状态逐个文件核实；不是依据 Commons 的站点元数据许可批量推断。印度土豆花菜的文件缺信息框，另外读取源文件页的 Flickr 审核记录确认作者 paul goyette 与许可。

### 拒绝或改选

- 鹰嘴豆炸饼：原做法实际上是鹰嘴豆咖喱搭配炸面饼，Falafel 是另一种菜，不采用英文关键词命中的炸豆丸子图。
- 鸡蛋三明治：候选有沙拉且未确认培根，与当前配方不符。
- 蒸水蛋：候选说明有土豆，不能用于本配方。
- 太阳蛋：候选明确是平底锅煎蛋，当前为微波炉做法；不采用。
- 印度土豆花菜：初选为多菜拼盘，改选主体清楚的单菜照片。
- 印度焖饭：初选肉类没有确认；改选说明明确为鸡肉的 Dum Biryani。
- 螺蛳粉：两个实物候选均有大块鸡脚/鸡翅等当前没有的主要配料；保留缺图。
- 皮蛋豆腐：下载候选覆盖较多木鱼花，当前没有该配料，保留缺图。
- B52：初选仅 128×220；较清晰候选分别是 STROH 80 或 Grand Marnier 顶层，当前配方是伏特加，不采用。
- 奶油蘑菇汤、印度奶茶：初选在现有横向头图里主体被裁掉过多，换图后复核；没有修改全站图片裁切规则。

## 既有资产保护

实施前工作区干净，菜谱 371 个 JSON、图片目录 184 个文件（183 个封面及非封面文件）。集合摘要算法沿用 [CB-012](../CB-012/CHECK.md#实施前基线)：递归文件排序，每项为相对路径、制表符和文件 SHA-256，再对换行连接后的内容取 SHA-256。

- 菜谱实施前摘要：`b0d05522e7897de6901a9a60b5edfb5b64bccd3cc7b9eb1b3e0dafb68776057b`。
- 旧图片实施前摘要：`2bcc6aca8d78d96ea21beafa466f899d3d7861e758af85c575c46b7a97887cf1`。
- 实施后菜谱摘要，以及排除本批 20 个新目录后的旧图片摘要均保持一致。

## 真实运行与浏览器

本地生产实例 `http://127.0.0.1:3099`，重启后启动扫描 203/371 道有封面。Browser 插件未提供，复用已安装 Playwright 和本机 Chrome，无新依赖。采用 frontend-testing-debugging 与 react-best-practices 技能，署名入口只是静态链接，无额外数据请求或渲染状态。

- 1440×1000、390×844：20 道菜各执行“搜索结果 → 照片真实解码 → 点击卡片 → 对应详情与头图”，共 40 条路径通过；页面非空，菜名与 URL 正确，没有框架错误界面、控制台错误、破图或页面横向溢出。
- 两种视口：首页点击“图片来源与许可” → 署名页 20 行 → 返回首页，通过；入口高度实测 44px；手机表格在自己的区域内可横向滚动，页面整体不溢出。
- 已查看全部 20 道实际桌面头图的截图汇总；换图后复核蘑菇汤、奶茶在两种视口的流程和署名页，复用其余 18 道有效证据。
- 截图在 `/private/tmp/cb013-<id>-<1440或390>-hero.png`，另有部分完整详情截图、`cb013-credits-390.png` 与 `cb013-credits-1440.png`；临时审核截图不进入 git。
- 没有做真实手机、厨房试做或用户观感验收。纵向蛋和杯子照片在横向头图中仍会呈现局部构图；图片的主要识别特征可见，不要求完整展示整个器皿。
