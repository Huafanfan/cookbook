# ADR-0008：其他开放许可图片与本地署名页

## 状态

已接受，2026-09-30；用户明确要求其他来源的真实图优先。实施范围见 [CB-013](../features/CB-013-open-license-cover-batch.md)。这是对 [ADR-0007](ADR-0007-reviewed-cover-sources.md) 逐张来源审核的补充，不改变其 AI 示意标识要求。

## 背景

HowToCook 图片数量有限，其他来源可提供相应菜品照片。部分许可要求署名、链接与改动说明，不能仅下载图片而丢失出处。

## 决策

- 逐个文件核实许可，不把站点的元数据许可当作图片许可。优先 Commons 等有明确文件作者、原始来源、开放许可的来源。
- 采用明确允许复用的公开领域、CC0、CC BY 或 CC BY-SA 图片；需署名的文件在随站点分发的本地署名页说明作者、文件页、许可、改动。CC BY-SA 图片文件本身继续按相应许可提供，不声称改变应用代码的许可。
- 署名页 `public/image-credits.html` 为这些署名事实的唯一权威位置，首页提供入口；Vite 与 Docker 构建阶段都包含 `public/`。无需添加运行期元数据读取、上传或新接口。
- 下载与审核仅在制作素材时进行，用户浏览只访问局域网本地 JPEG。旧图片不替换；AI 仍只用于找不到合适真实图的候选。

## 后果

增加少量静态 HTML 与首页入口，无新依赖、端口或运行期外网请求。署名页随前端构建进入版本和镜像，新图片仍随 `data/` 备份。网页浏览中的裁切、离线等比例缩放与 JPEG 编码需记录；照片不能证明本菜谱试做。
