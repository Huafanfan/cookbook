## 1. 目标与非目标

### 目标

1. 首页第一屏看见真实菜图，能快速搜索、筛选并决定做什么。
2. 手机详情尽快看到菜名、关键耗时、食材和做法；做菜时容易读步骤、点计时。
3. PC 多列浏览，手机单列；编辑和修改记录共用一套清爽视觉语言。
4. 系统处于深色模式时，菜谱站仍保持明亮外观。
5. 详情份量按已接受的 CB-001 规格只显示原文，修正当前实现残留的换算档位。

### 非目标

- 不改菜谱内容、搜索匹配、服务端排序、厨具判断、收藏/点赞写入、计时与步骤完成逻辑。
- 不生成菜谱照片、不伪造无图菜的成品图、不加入推荐算法、轮播、购物或账号。
- 不改变 [CB-001](CB-001-cooking-mode.md) 已接受的单页滚动、步骤勾选和计时交互。
- 不改服务器网络配置，不批量改写 `data/`；按用户 2026-09-29 授权，将本次前端发布到现有局域网服务。

## 2. 用户场景与状态流

```text
手机首页 → 看菜图 / 搜菜名或食材 / 选分类标签 → 打开详情
  → 看食材 → 滚动做法、勾步骤或计时 → 返回并恢复原筛选位置
PC 首页 → 多列浏览或搜索 → 详情 → 需要时编辑或看修改记录
```

手机是厨房主设备：竖屏、单手、离屏幕约 0.5–1.5 米；PC 主要用于浏览与录入。

## 3. 视觉系统与交互细节

方向：**明亮的家常餐桌**。真正的白色底 `#FFFFFF`、深叶绿 `#18593C`、深灰正文 `#233029`、少量柠檬黄 `#F3C94B`；食物照片提供暖色。照片不加改变菜色的滤镜。中文无衬线标题有鲜明层级，正文和控件字号明确；少用厚边框、橙色徽标与阴影。错误保留红色语义。交互变化才使用动效，尊重 `prefers-reduced-motion`。

### 首页

| 区域 | 手机 | PC |
| --- | --- | --- |
| 页头 | “今天吃什么”、显眼的“搜菜名或食材”；“我的厨具”在次级位置 | 站名、搜索、厨具同一清晰水平带 |
| 食欲入口 | 一张已有封面的精选菜大图；无可用封面则隐藏 | 最多三张已有封面的精选菜 |
| 浏览 | 分类先于标签；低频标签可在“筛选”中展开，选中与清除可见 | 分类与筛选在结果区上方，不在首屏铺满两行标签 |
| 结果 | 单列，大图或诚实无图样式；突出菜名、时间、难度和必要的厨具结论 | 宽图多列，宽度不足时减少列数 |

**精选入口**：从现有有封面的菜中手工指定少量入口；数据或封面不存在时隐藏该项，整个精选区为空则隐藏。它不改列表排序，不在搜索/筛选状态出现。视觉概念图中的轮播点、虚构菜名/耗时/食材和新筛选项均不属于规格。

搜索、分类和标签筛选仍由服务端完成；URL 查询与返回列表滚动位置继续恢复。手机收起标签时必须保留“筛选”入口、当前选中项和清除方式，不改变筛选语义。

### 详情与做菜

- 有封面时以宽图展示，但手机首屏仍应看见菜名和食材开头，沿用 [CB-007 §3.2](CB-007-images.md) 的信息优先规则；无封面时不留大块空白。
- 标题、摘要、份量、时间、难度与厨具结论分层排布；收藏、点赞、编辑、历史、常亮和字号可找到，但不抢食材与做法的视觉优先级。
- 食材的分组、用量、备注不变；做法保留单页滚动、步骤勾选、独立计时按钮和吸顶回位。
- 份量只展示菜谱原文人数与用量，不显示当前实现中与 [CB-001 §3.2](CB-001-cooking-mode.md) 冲突的 2–5 人缩放档位。
- 桌面利用宽度；手机步骤正文字号按厨房距离可读，主要点击区域 ≥44px。

### 编辑与修改记录

沿用 [CB-009](CB-009-edit-mode.md) 的分组、保存、草稿、字段错误、409 冲突、历史查看与恢复确认。仅统一颜色、排版和控件样式；手机输入字号 ≥16px、主要点击区域 ≥44px、无横向滚动。

## 5. 失败、降级与边界

| 情形 | 期望行为 | 用户可见反馈 |
| --- | --- | --- |
| 列表或筛选接口失败 | 保留可用界面与重试途径 | 错误文字显著 |
| 图片缺失、404 或载入慢 | 保持比例，不误示别的菜 | 无图占位，菜名可读 |
| 长菜名、摘要、标签 | 列表可截断摘要，详情完整显示 | 不溢出、不遮挡 |
| 精选数据不存在 | 隐藏该入口 | 无空白假推荐 |
| 常亮不支持 | 沿用 CB-001 降级 | 原有说明可见 |
| 保存、冲突、恢复失败 | 沿用 CB-009 保护 | 错误/冲突不被弱化 |
| 系统深色模式 | 本站继续明亮主题 | 文字与控件对比度可读 |

## 6. 验收标准

- [ ] 手机 390×844 与较窄视口：首页无横向滚动；搜索、筛选、进详情、返回恢复状态可完成。

- [ ] 系统深色和浅色偏好下均保持明亮；键盘焦点可辨。

## 8. 风险、回滚与依赖

- **风险**：当前仅 179/371 道菜有封面；图片优先版式在无图时也必须成立。头图过大可能把食材挤出手机首屏；收起标签可能降低可发现性。
- **回滚**：回退前端样式与组件即可；没有数据迁移。
- **依赖**：[CB-001](CB-001-cooking-mode.md)、[CB-005](CB-005-likes-favorites.md)、[CB-007](CB-007-images.md)、[CB-009](CB-009-edit-mode.md) 的既有行为。
